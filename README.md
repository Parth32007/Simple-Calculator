# Simple Calculator Web App

A modern **Flask-based calculator web application** with a clean pink UI design and interactive buttons.
This project performs basic arithmetic operations and is deployed publicly on cloud.

---

## Live Demo

🔗 https://simple-calculator-zpek.onrender.com

---

## 📌 Features

✅ Addition

✅ Subtraction

✅ Multiplication

✅ Division

✅ Percentage calculation

✅ Backspace delete functionality

✅ Modern responsive UI

✅ Flask backend API integration

✅ Public cloud deployment

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python Flask
* **Server:** Gunicorn
* **Deployment:** Render
* **Version Control:** Git & GitHub

## ⚙️ Installation & Run Locally

```bash
git clone https://github.com/Parth32007/Simple-Calculator.git
cd flask-calculator-ui
pip install -r requirements.txt
python app.py
```

Open browser:

```
http://127.0.0.1:5000
```
